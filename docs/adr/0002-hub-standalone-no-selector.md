# Hub remains standalone without track selector

The hub at `aradinka.dev` keeps the generalist portfolio as-is (`index.html` with Now, Recent 4, More). It does not surface cards linking to `/ai/`, `/data/`, `/eng/` and does not know tracks exist.

We chose this because the brief requires `aradinka.dev` to be the neutral fallback for Google/direct traffic, while subdomains are the targeted entry points distributed on CVs. Mixing them would dilute both stories. Tracks therefore do not link back to the hub and the hub does not link to tracks.
